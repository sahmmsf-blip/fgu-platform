# منصة مقرر الإدارة المالية – تطبيقات في ريادة الأعمال
جامعة فلوريدا العالمية (FGU) — التعليم المهني والمستمر · المحاضر: سهم هلالات العجارمة

- `index.html` صفحة الدخول (الطالب بالرقم الجامعي، والمحاضر باسم الدخول).
- `teacher.html` لوحة المحاضر: الطلبة، التقويمات، رصد العلامات، سجل العلامات، إتقان الأهداف، بنك الأسئلة، الإعدادات.
- `student.html` صفحة الطالب: علاماته، الاختبارات القصيرة، إتقانه للأهداف.
- `assets/config.js` رابط قاعدة البيانات والمفتاح العام فقط (آمن للنشر). كل الحماية داخل دوال قاعدة البيانات.
