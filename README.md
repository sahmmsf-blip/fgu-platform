# منصة مقرر الإدارة المالية – تطبيقات في ريادة الأعمال (الإصدار 1.2)
جامعة فلوريدا العالمية (FGU) — المحاضر: سهم هلالات العجارمة

بتصميم منصة السهم العلمي نفسه (المظاهر الأربعة، الأيقونات، الموقع، لوحة الطالب، ولوحة المحاضر الجانبية).

- `index.html`: موقع المقرر وصفحة دخول الطالب ولوحة الطالب واختباراته.
- `teacher.html`: لوحة المحاضر، وفيها:
  - القيادة، والتقويمات ورصد العلامات، وسجل العلامات
  - إتقان الأهداف، وبنك الأسئلة
  - الطلبة، والشعب والفصول والإعدادات
- `student.html`: تحويل تلقائي إلى `index.html` حتى تبقى الروابط القديمة تعمل.
- `assets/config.js`: فيه رابط قاعدة البيانات والمفتاح العام (publishable) فقط، وهذا آمن للنشر. الحماية كلها داخل دوال قاعدة البيانات.

قاعدة البيانات نفسها لم تتغيّر عن الإصدار 1.0، أي ملف SQL نفسه.

الإصدار 1.2:
- صفحة الطالب بلغتين (العربية والإنجليزية) من زر EN / ع.
- اسم الدخول وكلمة المرور الأولى = الرقم الجامعي.
- بنك الأسئلة 510 أسئلة.
